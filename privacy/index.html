隐私政策

Last updated: 2026-09-10

适用范围与开发者

本政策说明 Leo Liu 提供的所见 Seen 1.0 App 与本官网的数据处理。Last updated: 2026-09-10。

由你选择的照片与本地经历

Seen 读取你主动选择且授权访问的照片，以及可用的拍摄时间和位置，用于整理材料、确认地点与回看经历。原系统照片保持只读，Seen 不修改或删除 Apple Photos 资产。用户显式确认才创建经历；核心经历、收藏和派生结果当前主要保存在本机。Seen 没有自有账号或内容同步服务器。

可选 AI 与 DeepSeek

AI 由你主动开启。V1 使用 BYOK，即自行配置 DeepSeek API Key；当前不支持在 App 内选择其他 Provider。确认发送前可查看服务商、目的与本次资料范围。请求直接发往 DeepSeek；鉴权时 API Key 会发送给 DeepSeek，不经过 Seen 自有服务器。你可以不使用 AI，继续使用全部当前 Free 核心功能。

API Key 的存放

API Key 使用 iOS Keychain 的本设备专用、不同步条目保存。Seen 不将其写入内容 JSON、本地用量记录、普通日志或 iCloud，不在 App 中内置共享生产 Key。可以在设置中更新或删除连接；删除不会撤回已经发送的请求，也不会删除服务商已持有的数据。

AI 请求包含什么

照片理解可能发送本地缩小的 JPEG 与 Live Photo 必要帧（最多三帧），不发送完整视频、音频或原始照片文件。图像本身仍可能包含个人信息。联系分析主要发送所选范围内的日期/拍摄时间、照片数、已确认地点名称/类别、已有画面线索及粗时间/距离信息；不发送精确坐标、详细地址或本机照片/经历标识。具名地点仍可能透露具体位置。发送内容取决于你明确选择的操作与范围。

第三方处理

DeepSeek 的留存、使用与跨境处理受其现行服务条款、隐私政策及你的账户设置约束；Seen 不承诺第三方永不保存、不训练或固定保留期限。请在发送前阅读服务商政策，避免发送不愿交给第三方的内容。AI 结果可能错误；失败或模型输出不会直接改写你已确认的真实经历。

地图与分享

地图搜索、底图和导航使用 Apple 服务，相关查询或位置会按你的操作交给 Apple。系统分享由你选择接收方；导出的照片、文字和地点随分享内容交给该接收方，受其处理规则约束。

用量与运行观察

Usage Observation 只在本机记录必要的操作类型、状态、时间、token/资源用量及是否可用等最小元数据，不记录源照片内容或 API Key，不上传为 Seen 分析数据。服务商可以独立记录服务调用与费用。Seen 未接入自有广告、跨 App 追踪或分析上传 SDK。

保存、删除与恢复

本地记录通常保留至你主动删除。删除经历或收藏先移入本机最近删除，当前没有定时清空；可恢复或再次确认后彻底删除。系统原照片不受影响。撤销照片权限不会自动删除已确认经历。V1 没有应用内云同步或完整备份恢复；系统设备备份由系统与用户设置决定，不能将本地存储理解为所有文件均不进入系统备份。

官网访问与支持联系

官网是 GitHub Pages 静态页面，没有本站添加的 Analytics、广告、追踪脚本、表单或 Cookie。托管方 GitHub 可能处理 IP 地址和请求等访问技术信息。你发邮件联系支持时，Leo Liu 会处理你的邮箱和你主动提供的内容以回复、排查问题；仅在处理问题及履行适用义务所需范围内保留，不承诺未经核实的固定天数。

你的选择与联系

可通过系统设置管理照片/定位权限，通过 Seen 设置管理 AI 连接，通过最近删除管理记录。涉及支持邮件的查阅、更正或删除请求，可联系 Leo Liu；仅存于你设备上的内容需由你在设备上操作。服务商账户数据请求应向对应服务商提出。联系开发者 Leo Liu：liuh11260@gmail.com。请仅提供解决问题需要的信息，不发送 API Key、完整相册或其他敏感资料。
