Seen 如何处理你的照片

Seen 不提供账号云端图库。核心记录、已保存作品和分析缓存保存在设备上，原照片仍由 Apple Photos 管理。基础整理与回顾无需 AI；主动使用可选照片理解时，所选图片会直接发送至 DeepSeek，需要你自备 API Key，费用按 DeepSeek 账户规则收取。

照片权限与加入

照片访问权限由 iOS 管理，可以只允许选定照片。明确选择加入后，Seen 读取已有拍摄时间、可用位置等信息，在本机整理经历。附近功能仅在授权后使用本次位置，不把当前位置写成照片地点。

本机记录与备份

无需 Seen 账号，当前不提供账号云同步。核心记录、作品和相关缓存保存在本机，支持本地资产备份与恢复。备份不包含系统照片原件；换机还需通过 Apple Photos 等方式迁移原件，并保持相应访问权限。请妥善保管含私人内容的备份。

原照片与地点

自动整理、回顾和分享不会删除原照片。原片删除必须另行选择并完成系统确认。缺少可靠地点时不会猜测位置；已有合法地点修正可用于回看。地图与地点类回顾只使用对应范围的可靠信息，经历段数不等于核验过的到访次数。

可选照片理解会发送图片

可选 AI 仅接入 DeepSeek，需你自行配置 DeepSeek API Key，费用由 DeepSeek 按账户规则收取。照片理解须独立确认选片范围与费用，直接发送长边最多1024像素、去除EXIF/GPS等元数据的压缩静态 JPEG，不发送原文件、Live Photo帧或视频。画面本身仍可能透露人物、地址或其他个人信息，去元数据不等于匿名。

文字请求与授权

可选文字关系分析同样使用你的 DeepSeek API Key，费用由 DeepSeek 收取。请求可使用已加入经历的目录，以及本次取证范围的时间、地点名称、备注、标签与已有结构化线索。开启首页 AI 模式并授权期间，材料变化或明确生成可触发后续文字请求，不是每次都重新确认。独立润色只发送另行选定的原文。AI 不直接改写经历或已保存作品。

网络与服务商

地图和地点搜索使用 Apple 地图服务，需要网络；可选 AI 使用你的 DeepSeek API Key 直连 DeepSeek，费用按其账户规则收取。基础整理与回顾不依赖 Seen 内容服务器。DeepSeek 的内容保存、训练、删除及跨境处理适用其条款与账户规则，Seen 不承诺服务商零留存或不训练。

停止与完整政策

关闭首页 AI 模式会取消当前照片理解和关系分析任务；独立润色仍只在你明确提交选文时请求。可撤销照片理解授权或删除连接来停止对应新请求，已经发送的内容无法撤回。完整处理规则见隐私政策。
